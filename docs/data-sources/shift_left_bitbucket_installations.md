# orcasecurity_shift_left_bitbucket_installations (Data Source)

Lists all Orca Bitbucket shift-left server connections (installations) for fleet-wide for_each. Use each installation's `id` as `installation_id` on `orcasecurity_shift_left_bitbucket_account` / repository resources. `account_id` here is the token-scope workspace/project slug from the installation credential — not the Orca account UUID and not necessarily the same field as on `orcasecurity_shift_left_bitbucket_account`.

## Example Usage

```terraform
data "orcasecurity_shift_left_bitbucket_installations" "all" {}

output "bitbucket_installation_ids" {
  value = [for i in data.orcasecurity_shift_left_bitbucket_installations.all.installations : i.id]
}
```
